### A rounder second wave on the icon
The icon's outer sound wave had a kink on each side (two dots straight down, then a step outwards). Two of its dots moved one column out, so it is now a round arc around the speaker, the same shape as the inner wave: the two waves read as parallel. The themed (monochrome) icon has the same fix. With Nothing Launcher Plus, the live icon still animates both waves.

Installs straight over v1.0.75: no uninstall needed.
