### What's new
- **Signed with a permanent key.** From this release on, every update installs straight over the previous one, also through Komi Store.
- **Mono / Stereo switch at once.** With module [v0.9.4+](https://github.com/Dr-Essence/CMF-true-stereo/releases/latest) the switch applies immediately (the sound stops for a moment; press play again). It only asks for a restart when switching live is not possible.
- **Left and right follow the screen.** With module v0.9.5, turning the phone the other way swaps the channels, so the stereo is never reversed.

> ⚠️ **Uninstall the previous version first, one last time:** earlier builds were signed with temporary keys. After this one, no more uninstalls.
