### Find the stereo settings in Settings search
Type a setting's name in Nothing's Settings search (for example "bass guard", "earpiece level" or "stereo") and it is listed, with "Stereo speakers" under it; a tap opens that page inside Settings.

Needs the LSPosed part: add **Settings Intelligence** (`com.android.settings.intelligence`) to the app's scope in LSPosed, then force-stop Settings Intelligence once (or reboot). With both editions installed, the settings are listed once.

Installs straight over v1.0.79: no uninstall needed.
