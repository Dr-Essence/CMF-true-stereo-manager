### What's new
- **Stereo in Nothing Settings** (optional, with LSPosed): a **Stereo speakers** row in Settings > Sound, right above Dirac, and its own page inside Settings, in Nothing's own rows: Earpiece speaker, Stereo, earpiece and speaker level as dots, Speaker boost as dots, Deep bass guard and Earpiece leveller as pills, Earpiece limiter, each with a description. Enable one edition in LSPosed (scope: Settings), then force-stop Settings.
- **Quick Settings tile:** "Stereo" (CMF Stereo) / "Stereo Pro" (Pro). A tap switches Mono / Stereo, a long press opens the app.
- **Instant sync without root:** the Settings row, its page and the tile show changes right away, wherever they are made (the apps, the tile, stereoctl, the module itself), without a root call or a Magisk toast each time. Needs module [v1.0.6](https://github.com/Dr-Essence/CMF-true-stereo/releases/latest) for changes made outside the apps.
- **Internal storage only:** LSPosed cannot see apps on adopted storage, so both editions now install on internal storage, and offer to move there if an override put them elsewhere.

Update the module to v1.0.6 too.

Installs straight over v1.0.60: no uninstall needed.
