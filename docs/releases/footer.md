
### Two editions, installable side by side
- **CMF Stereo** (`clean`) – for everyday use: Nothing style with NDot type, on/off, Mono/Stereo, earpiece and speaker level on a plain 1–10 scale.
- **CMF Stereo Pro** (`pro`) – the full manager with developer tools.

Needs root and the [CMF-true-stereo](https://github.com/Dr-Essence/CMF-true-stereo/releases/latest) module (v0.9.0+ for Mono/Stereo). The module is a Magisk zip: flash it in Magisk / KernelSU / APatch.

### Stay updated with Komi Store
Shout-out to **[Komi Store](https://github.com/komi-store/komi-store)**, the free, open-source app store for GitHub releases. Search for *CMF-true-stereo-manager*, install your edition, and Komi Store keeps it updated from these releases.
