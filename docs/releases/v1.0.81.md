### Settings search finds the stereo settings
v1.0.80's settings did not show up in Settings search. Settings search only reads an app's settings again when the app's version changes, so if it looked before the LSPosed part was on, it skipped them until the next update; and with both editions installed, an older edition could hide the newer one's settings. Both are fixed.

Update **both editions** if both are installed. In LSPosed, keep **Settings Intelligence** ticked in the app's scope, then force-stop Settings Intelligence once (or reboot) and search for "bass guard".

Installs straight over v1.0.80: no uninstall needed.
