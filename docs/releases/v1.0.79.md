### A bolder icon in Nothing's icon style
With Nothing Launcher's **Nothing** icon style, the speaker icon looked small and grey next to Nothing's own icons: the launcher draws an app's one-colour layer smaller than the full icon. That layer is now larger, with bolder dots, so it sits like Nothing's own glyphs. The coloured icon is unchanged.

If CMF Stereo Pro still shows the older wave with a kink on each side, update Pro too: both editions get the same icon.
