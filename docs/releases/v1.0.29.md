### What's new
- **About 1 MB instead of ~100 MB.** The release build is now shrunk, and an icon library the app never used is gone.
- **Faster.** After each tap the app refreshes in a single root call instead of about fourteen. Best with module [v0.9.3](https://github.com/Dr-Essence/CMF-true-stereo/releases/tag/v0.9.3), which makes switching the earpiece on and off near-instant; older modules still work, just slower.

> ⚠️ **Uninstall the previous version first:** the signing key changed, so Android won't install this over the old app.
