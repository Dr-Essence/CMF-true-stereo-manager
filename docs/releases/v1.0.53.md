### What's new
- **Both speakers in games with "While playing":** with module [v1.0.3](https://github.com/Dr-Essence/CMF-true-stereo/releases/latest), the earpiece now joins in for games and every other app, not only music players. Update the module too: that is where the fix is.
- **Nothing OS update notice:** after a Nothing OS update (module v0.9.8+), CMF Stereo shows a NOTHING OS UPDATED panel (stereo off, stock sound until the module supports the new build) and Pro a "Nothing OS" status row.
- **Pro:** the help for PLAYBACK_CTL explains the list of DSP task switches the module now watches.

Installs straight over v1.0.39: no uninstall needed.
